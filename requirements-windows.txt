# Native Windows install requirements (no Docker).
#
# Differences from requirements.txt (the Linux/Docker set):
#   • DB driver:    mysqlclient  →  mssql-django + pyodbc  (MS SQL Server)
#   • libmagic:     python-magic →  python-magic-bin       (bundles the DLL)
#   • gunicorn:     dropped (Linux WSGI server; Windows uses daphne/ASGI)
#   • python-ldap:  omitted by default (needs a prebuilt Windows wheel; only
#                   required if a client enables AD/LDAP — see notes below)
#
# Elasticsearch client libs are kept (pure Python). With ELASTICSEARCH_ENABLED=
# False they never contact a server — search falls back to the database.
#
# Install (from an activated venv):
#   pip install -r requirements-windows.txt
#   python -m spacy download en_core_web_sm   # if not pulled by the pin below
# ──────────────────────────────────────────────────────────────────────────────
